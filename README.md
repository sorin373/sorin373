Collaborative prototype combining machine learning, rule-based decision logic, ONNX inference, C++ simulation and Python visualisation.

## My Contribution

I developed the C++ simulation backend used to generate and model multi-threat scenarios.

My work included:

- implementing randomised threat and target scenario generation;
- modelling two-dimensional target-seeking trajectories;
- implementing heading correction and turn-rate constraints;
- modelling lateral acceleration, velocity control and simplified aerodynamic drag;
- detecting target impact and map-boundary conditions;
- adding simulated sensor noise to position measurements;
- calculating risk labels based on threat and target categories;
- normalising telemetry features;
- exporting time-series simulation data to CSV for downstream machine-learning and visualisation components.

The simulation was designed as a modular data-generation component within the wider PiuPiuDefense pipeline.
